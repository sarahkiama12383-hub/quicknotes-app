# QuickNotes

QuickNotes is a lightweight web application that allows users to write, categorize, search, and store short notes in the browser.

## Features
- Add notes under Personal, Work, or Study categories.
- Input validation to reject empty notes or notes exceeding 200 characters.
- Live keyword search to filter saved notes.
- Persistent storage using browser localStorage.
- Responsive design for screen sizes under 600px.

## How to Run Locally
1. Clone or download the repository files.
2. Open `index.html` in any browser.

## What I Learned
1. Building dynamic list cards using `createElement` and safe text rendering with `textContent`.
2. Filtering Javascript arrays dynamically using string methods like `includes()`.
3. Managing application state using browser `localStorage` with `JSON.parse` and `JSON.stringify`.
